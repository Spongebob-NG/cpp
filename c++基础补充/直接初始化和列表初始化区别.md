# C++ 直接初始化与列表初始化

## 一、基本写法

```
int a(10);    // 直接初始化
int b{10};    // 列表初始化
int c = {10}; // 拷贝列表初始化
```

三种写法都能将变量初始化为 `10`，但遵循的初始化规则有所不同。

## 二、核心区别

### 1. 是否允许窄化转换

窄化转换是指可能造成数据精度或取值范围损失的类型转换。

```
int a(3.14);  // 可以编译，结果为 3
int b{3.14};  // 编译报错
```

- 直接初始化：允许部分窄化转换，例如 `double` 转 `int`。
- 列表初始化：禁止窄化转换，编译器会直接报错。

注意：列表初始化并不是禁止所有类型转换，只禁止标准规定的窄化转换。

### 2. 类对象的构造函数选择

如果一个类同时具有普通构造函数和 `std::initializer_list` 构造函数，列表初始化会优先考虑 `std::initializer_list` 构造函数。

```
#include <iostream>
#include <initializer_list>

class Demo {
public:
    Demo(int x) {
        std::cout << "普通构造函数\n";
    }

    Demo(std::initializer_list<int> values) {
        std::cout << "列表构造函数\n";
    }
};

Demo a(10);  // 调用 Demo(int)
Demo b{10};  // 优先调用 initializer_list 构造函数
```

因此，圆括号和花括号并不总是等价的。

### 3. 容器初始化的区别

以 `std::vector` 为例：

```
#include <vector>

std::vector<int> a(5, 10);
std::vector<int> b{5, 10};
```

- `a(5, 10)`：创建 5 个元素，每个元素都是 10。
- `b{5, 10}`：创建 2 个元素，分别为 5 和 10。

原因：`std::vector` 提供了 `std::initializer_list` 构造函数，花括号初始化会优先考虑该构造函数。

## 三、对比总结

| 对比项                               | 直接初始化 `T x(...)`      | 列表初始化 `T x{...}`          |
| ------------------------------------ | -------------------------- | ------------------------------ |
| 基本类型初始化                       | 支持                       | 支持                           |
| 调用普通构造函数                     | 支持                       | 支持                           |
| 禁止窄化转换                         | 不会统一禁止               | 会                             |
| 优先考虑 `initializer_list` 构造函数 | 不适用该优先规则           | 会                             |
| 常见用途                             | 明确使用构造函数初始化对象 | 安全初始化，减少意外的数据损失 |

## 四、记忆口诀

1. **圆括号**：常规初始化方式，按构造函数规则选择。
2. **花括号**：禁止窄化转换，类对象初始化时优先考虑 `initializer_list` 构造函数。
3. **容器要注意**：圆括号可能表示元素数量和初始值，花括号可能表示具体的元素列表。

实际编程时，应根据类型和构造函数选择合适的初始化方式，不能简单认为圆括号和花括号只是书写风格不同。
