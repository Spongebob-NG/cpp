#### 仿函数

###### 具体概念

是一个重载了函数调用运算符 operator()的类或结构体 行为像函数 能被调用 比如obj(arg1,arg2)  所以叫做“仿函数”

```c++
#include <iostream>

// 定义一个仿函数类
struct Multiplier {
    int factor;
    Multiplier(int f) : factor(f) {}

    // 重载 operator()
    int operator()(int x) const {
        return x * factor;
    }
};

int main() {
    Multiplier times3(3); // 实例化一个对象
    std::cout << times3(5); // 像调用普通函数一样调用对象，输出 15
}
```

###### 主要作用

1. 有**内部状态**   普通函数要记录状态的话只能通过全局变量或者静态变量 是**非线程安全**的（因为是所有线程共享的 并且如果**加了互斥锁的话可能更严重 会导致死锁**）是**不可重入**的 （因为有信号或者中断 并且调用的是同一个函数的话 会改掉static或者全局变量 再次返回到这个函数的时候变量就被改了） 并且也**无法同时存在多套不同配置**（比如上面那个代码段里面的例子 实例化的对象可以是3 也可以是5或者任意整数）
