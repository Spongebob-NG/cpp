#### 仿函数

###### 具体概念

是一个重载了函数调用运算符 operator()的类或结构体 行为像函数 能被调用 比如obj(arg1,arg2)  所以叫做“仿函数”

```c++
#include <iostream>

// 定义一个仿函数类
struct Multiplier {
    int factor;
    Multiplier(int f) : factor(f) {}

    // 重载 operator()
    int operator()(int x) const {
        return x * factor;
    }
};

int main() {
    Multiplier times3(3); // 实例化一个对象
    std::cout << times3(5); // 像调用普通函数一样调用对象，输出 15
}
```

###### 主要作用

1. 有**内部状态**   普通函数要记录状态的话只能通过全局变量或者静态变量 是**非线程安全**的（因为是所有线程共享的 并且如果**加了互斥锁的话可能更严重 会导致死锁**）是**不可重入**的 （因为有信号或者中断 并且调用的是同一个函数的话 会改掉static或者全局变量 再次返回到这个函数的时候变量就被改了） 并且也**无法同时存在多套不同配置**（比如上面那个代码段里面的例子 实例化的对象可以是3 也可以是5或者任意整数）

2. 编译期确定类型 支持极高强度的**内联**优化

   1. **普通函数的指针**传给模板算法 比如sort时 编译器拿到的是一个**运行时**的函数地址 调用时**需要跳转 难以内联**
   2. 每个仿函数是一个独立的c++类型 模板展开时**具体实现完全暴露在编译器眼前** 能直接展开插入到调用处 **消除函数调用开销**（内联）

3. 仿函数是STL关联**容器**和**堆**的“**类型参数**”必需品

   **sort**的第三个参数接收的是一个**函数参数** （对象或函数指针）

   但是优先队列、set、map在声明的时候 要求在<>提供**比较器**的**类型**

   ```c++
   // 模板定义：template<class T, class Container, class Compare> class priority_queue;
   // 第三项必须是一个“类型名”，不能直接传普通函数名！
   std::priority_queue<int, std::vector<int>, std::greater<int>> pq;
   ```

   如果不用仿函数的话 就得写很复杂的**函数指针类型**

   ###### 注意事项

   greater<>在优先队列里面是**小顶堆** 这个**跟堆排序有区别**   逻辑是这样的：如果比较的结果为true的话 前面的优先级低 后面的优先级高。 

   对于**greater**来说，符号是'>'，如果a>b的话，代表a的优先级低，也就是大的数优先级低，小的数优先级高，所以是**从小到大**排列

   对于**less**来说，符号是'<'，小的优先级低，大的优先级高，是**从大到小**排列
