###### 先导

1. **在C语言标准库前期的版本里面 是没有线程库的** 要使用线程库的话 **得用POSIX的线程库** 对于C语言来说**属于第三方库**  但是C语言在C11开始也有自己的线程库了 只不过大家还是习惯用POSIX的线程库.  **c++从c++11开始引入了官方标准线程库**  由于是标准的库 所以定义的是**统一的一套接口**(跨平台抽象)  在不同的操作系统底层会接入不同的操作系统的API 比如linux下就是POSIX的pthread windows下又是另一套接口
2. 对于C标准库  使用POSIX线程库的时候  编译时要加上-lpthread选项 链接上对应的线程支持库

#### 多线程编程

###### 创建线程

**pthread_create**

```c++
#include <pthread.h> //头文件
int pthread_create(pthread_t *thread, const pthread_attr_t *attr,void *
(*start_routine) (void *), void *arg);
功能：创建一个分支线程
参数1：线程号，通过参数返回，用法：在外部定义一个该类型的变量，将地址传递入函数，调用结
束后，该变量中即是线程号
参数2：线程属性，一般填NULL，让系统使用默认属性创建一个线程
参数3：是一个回调函数，一个函数指针，需要向该参数中传递一个函数名，作为线程体执行函数
该函数由用户自己定义，参数是void*类型，返回值也是void *类型
参数4： 是参数3的参数，如果不想向线程体内传递数据，填NULL即可
返回值：成功返回0，失败返回一个错误码（非linux内核的错误码，是线程支持库中定义的一个错
误码）
Compile and link with -pthread. //编译时需要加上 -pthread选项
```

**怎么理解 void `*`(`*`start_routine) (void `*`)**

看到`*`跟名字结合在一起 就知道这个是一个指针  并且是一个函数指针  传递的参数是void `*`类型 返回的类型也是void `*`

###### 线程号获取

**pthread_self**

```c++
#include <pthread.h>
pthread_t pthread_self(void);
功能：获取当前线程的线程号
参数：无
返回值：返回调用线程的id号，不会失败
```

###### 线程退出

**pthread_exit**

```c++
#include <pthread.h>
void pthread_exit(void *retval);
功能：退出当前线程
参数：表示退出时的状态，一般填NULL
返回值：无
```

###### 线程资源回收

**pthread_join**

```c++
#include <pthread.h>
int pthread_join(pthread_t thread, void **retval);
功能：阻塞回收指定线程的资源
参数1：要回收的线程线程号
参数2：线程退出时的状态，一般填NULL
返回值：成功返回0，失败返回一个错误码
```

**怎么理解pthread_exit的参数以及pthread_join的第二个参数**

如果说线程退出的时候 需要把某个计算结果 或者某个执行后的结果 交给主线程或者其他线程的话 就得**在pthread_exit的时候传入该结果的地址**  然后这个**地址就会被内核保存**着  之后**其他线程想要拿到这个已经退出的线程的结果**的话 就要先**声明一个指针变量接收那个内核保存着的地址**  但是**要想改变一个指针的指向 就得用二级指针传参** 这就是pthread_join的第二个参数是二级指针的原因

**需要注意!!!**

线程执行函数执行完了之后 **要返回的地址 一定不能是局部变量的地址!!!**这部分地址会被回收!  按理来说只要是能长期存在的地址 都能返回 比如静态区 堆区



###### 线程分离态

**pthread_detach**

```c++
#include <pthread.h>
int pthread_detach(pthread_t thread);
功能：将指定线程设置成分离态，被设置成分离态的线程，退出后，资源由系统自动回收
参数：要分离的线程号
返回值：成功返回0，失败返回一个错误码
```

##### 互斥锁

###### 创建互斥锁

只需要定义一个pthread_mutex_t 类型的变量就是创建了一个互斥锁

pthread_mutex_t mutex;

###### 初始化互斥锁

**pthread_mutex_init**

```c++
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER; //静态初始化
int pthread_mutex_init(pthread_mutex_t *restrict mutex,const
pthread_mutexattr_t *restrict attr);
功能：初始化互斥锁变量
参数1：互斥锁变量的地址，属于地址传递
参数2：互斥锁属性，一般填NULL，让系统自动设置互斥锁属性
返回值：成功返回0，失败返回错误码
```

###### 获取锁资源

**pthread_mutex_lock**

```c++
int pthread_mutex_lock(pthread_mutex_t *mutex);
功能：获取锁资源,如果要获取的互斥锁已经被其他线程锁定，那么该函数会阻塞，直到能够获取锁资源
参数：互斥锁地址，属于地址传递
返回值：成功返回0，失败返回一个错误码
```

###### 释放锁资源

**pthread_mutex_unlock**

```c++
int pthread_mutex_unlock(pthread_mutex_t *mutex);
功能：释放对互斥锁资源的拥有权
参数：互斥锁变量的地址
返回值：成功返回0，失败返回一个错误码
```

**销毁互斥锁**

```c++
int pthread_mutex_destroy(pthread_mutex_t *mutex);
功能：销毁互斥锁
参数：互斥锁变量的地址
返回值：成功返回0，失败返回一个错误码
```



##### 无名信号量

**为什么要叫无名信号量?**

因为"无名"就是说 没有一个系统可见的名字 没有挂载到虚拟文件系统里面  仅仅由一个内存变量表示



###### 创建无名信号量 

只需要定义一个sem_t类型的变量

###### 初始化无名信号量

**sem_init**

```c++
#include <semaphore.h>
int sem_init(sem_t *sem, int pshared, unsigned int value);
功能：初始化无名信号量，最主要是初始化value值
参数1：无名信号量的地址
参数2：判断进程还是线程的同步
0：表示线程间同步
非0：表示进程间同步，需要创建在共享内存段中
参数3：无名信号量的初始值
返回值：成功返回0，失败返回-1并置位错误码
```

###### 申请无名信号量的资源(P)

**sem_wait**

```c++
#include <semaphore.h>
int sem_wait(sem_t *sem);
功能：阻塞申请无名信号量中的资源，成功申请后，会将无名信号量的value进行减1操作，如果当
前无名信号量的value为0，则阻塞
参数：无名信号量的地址
返回值：成功返回0，失败返回-1并置位错误码
```

###### 释放无名信号量的资源(V)

**sem_post**

```c++
include <semaphore.h>
int sem_post(sem_t *sem);
功能：将无名信号量的value值增加1操作
参数：无名信号量地址
返回值：成功返回0，失败返回-1并置位错误码
```

###### 销毁无名信号量

**sem_destroy**

```c++
#include <semaphore.h>
int sem_destroy(sem_t *sem);
功能：销毁无名信号量
参数：无名信号量地址
返回值：成功返回0，失败返回-1并置位错误码
```



##### 条件变量

**条件变量的含义以及与无名信号量的区别**

**条件变量**顾名思义就是 **如果满足了某个条件 就会在等待队列唤醒一个或多个线程   没有计数的概念**  而**无名信号量**有**计数**的概念 是通过P和V来操作的  并且偏向一个个来(这个"一个个来"不是说只能有一个线程执行,而是说P和V操作是按照单位来扣减/增加的)



###### 创建一个条件变量

只需定义一个类型为pthread_cond_t的全局变量

###### 初始化条件变量

**pthread_cond_init**

```c++
pthread_cond_t cond = PTHREAD_COND_INITIALIZER; //静态初始化
int pthread_cond_init(pthread_cond_t *restrict cond,const pthread_condattr_t
*restrict attr);
功能：初始化条件变量
参数1：条件变量的起始地址
参数2：条件变量的属性，一般填NULL
返回值：成功返回0，失败返回一个错误码
```

###### 消费者线程进入等待队列

**pthread_cond_wait**

```c++
int pthread_cond_wait(pthread_cond_t *restrict cond,pthread_mutex_t
*restrict mutex);
功能：将线程放入休眠等待队列，等待其他线程的唤醒
参数1：条件变量的地址
参数2：互斥锁，由于多个消费者线程进入等待队列时会产生竞态，为了解决竞态，需要使用一个互斥锁
返回值：成功返回0，失败返回错误码
```

###### 生产者唤醒休眠队列中的任务

**pthread_cond_broadcast**

```c++
int pthread_cond_broadcast(pthread_cond_t *cond);
功能：唤醒条件变量维护的队列中的所有消费者线程
参数：条件变量的地址
返回值：成功返回0，失败返回错误码
```

**pthread_cond_signal**

```c++
int pthread_cond_signal(pthread_cond_t *cond);
功能：唤醒条件变量维护的队列中的第一个进入队列的消费者线程
参数：条件变量的地址
返回值：成功返回0，失败返回错误码
```



###### 销毁条件变量

**pthread_cond_destroy**

```c++
int pthread_cond_destroy(pthread_cond_t *cond);
功能：销毁一个条件变量
参数：条件变量的地址
返回值：成功返回0，失败返回错误码
```

**流程**

**线程函数体:**pthread_mutex_lock --> pthread_cond_wait --> 干活 --> pthread_cond_unlock --> pthread_exit(nullptr)

**注意事项:** pthread_wait的时候 进入了休眠队列 **会自动先把锁释放 再进入休眠** 所以这个时候其他的线程是能再次拿到锁进入休眠队列的 不是说一定要等到第一个线程执行完pthread_cond_unlock之后才能拿到锁



#### c++11中的多线程

在讲c++11中的多线程之前 先来讲讲c++中的**RAII(资源获取即初始化)**   其中 **"即" 的意思是"就要"**,也就是说,只要**一获取到资源 就要立马把获取到的资源绑定到某个对象的生命周期**  也可以直接在构造函数里面获取资源  然后**析构函数里面一定要把获取到的资源都给析构掉**    这样的话 即使中间出了错 或者return之前忘了把获取到的资源还给系统  析构函数也会自动调用 把资源归还 (因为出错的时候本质上还是会记录下每一层的栈 **C++ 极度依赖栈上对象的生命周期来驱动整个系统的内存与资源管理**  会通过后进先出逆序调用它们的析构函数)  如果是大数据的话  栈与堆的分工协作就是 **栈管头,堆管肉**  也就是说  **生命周期属于栈  但是数据是在堆上存放的**
