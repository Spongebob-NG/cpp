`std::list` 是 C++ 标准库中的**双向循环链表**（Doubly-Linked List）。其核心价值在于：**非连续存储**、**任意位置操作均为 $O(1)$**、**节点插入与删除绝不导致其他迭代器失效**。



以下是 `std::list` 全套核心 API 的系统笔记与底层机理说明。



### 一、 核心内存拓扑与迭代器模型

1. **底层物理结构**：

   每个节点独立分配在堆（Heap）内存中，包含三个字段：`prev` 指针、`next` 指针、`data` 数据实体。

2. **哨兵节点与边界区间**：

   - `begin()`：指向**第一个有效数据节点**。
   - `end()`：指向**末尾哨兵节点（Past-the-end）**，该节点不包含有效数据，**绝对禁止对其解引用（`\*end()` 为非法访问）**。
   - `front()` 等价于 `*begin()`；`back()` 等价于 `*(--end())`。

### 二、 迭代器与元素访问

由于内存不连续，`std::list` 不支持下表运算符（无 `[]`，无 `at()`），仅支持**双向迭代器（Bidirectional Iterator）**。



| **API 原型**          | **作用与用法**                       | **复杂度** | **注意事项 / 底层行为**                        |
| --------------------- | ------------------------------------ | ---------- | ---------------------------------------------- |
| `front()`             | 获取首元素引用：`int x = l.front();` | $O(1)$     | 链表为空时调用触发未定义行为（UB）             |
| `back()`              | 获取尾元素引用：`int y = l.back();`  | $O(1)$     | 链表为空时调用触发未定义行为（UB）             |
| `begin()` / `end()`   | 获取首节点 / 哨兵尾节点的迭代器      | $O(1)$     | `end()` 仅用于区间闭环比较，不可解引用         |
| `rbegin()` / `rend()` | 反向迭代器（从尾向头遍历）           | $O(1)$     | `++rit` 实际在物理内存上向 `prev` 前驱方向移动 |

C++

```
#include < list >
#include < iostream >

std::list< int > l = {10, 20, 30};

// 正向遍历
for (auto it = l.begin(); it != l.end(); ++it) {
    std::cout << *it << " ";
}

// 严禁写：it = it + 2; （编译报错，双向迭代器不支持算术直接相加）
// 若需位移，使用 std::advance:
auto it = l.begin();
std::advance(it, 2); // 内部执行两次 ++it，耗时 O(N)
```

### 三、 插入与构造（$O(1)$ 时间复杂度）

`std::list` 的插入操作**不会引起任何已有迭代器失效**。



| **API 原型**             | **功能描述**                        | **内存与性能开销**                                           |
| ------------------------ | ----------------------------------- | ------------------------------------------------------------ |
| `push_front(val)`        | 头部插入元素                        | 堆上分配 1 个新节点，改动 4 个指针，调用拷贝/移动构造        |
| `emplace_front(args...)` | 头部**就地构造**元素                | **Placement new** 在新分配节点上直接构造对象，避免临时对象产生 |
| `push_back(val)`         | 尾部插入元素                        | 插入到 `end()` 前方，常规构造                                |
| `emplace_back(args...)`  | 尾部**就地构造**元素                | 高频推荐，替代 `push_back`                                   |
| `insert(pos, val)`       | 在迭代器 `pos` **正前方**插入单元素 | 返回指向**新插入节点**的迭代器，`pos` 依然有效               |
| `emplace(pos, args...)`  | 在迭代器 `pos` **正前方**就地构造   | 返回指向**新插入节点**的迭代器                               |

C++

```
std::list< std::pair< int, int > > l;

// 1. insert 用法（需构造临时 pair）
auto it = l.begin();
l.insert(it, {1, 100});

// 2. emplace / emplace_front 用法（直接传构造参数，零额外拷贝）
l.emplace_front(2, 200); 
l.emplace_back(3, 300);
```

### 四、 删除与内存清理（`erase` 及相关 API）

删除操作将调用对象的析构函数，并通过分配器将节点的堆内存归还给操作系统。**只有被删除节点的迭代器会失效，其余迭代器依然安全**。



#### 1. 单节点与区间删除：`erase()`

- **函数签名**：

  C++

  ```
  iterator erase(const_iterator pos);                          // 1. 删单个
  iterator erase(const_iterator first, const_iterator last);    // 2. 删区间 [first, last)
  ```

- **核心返回值**：返回**被删除节点的下一个有效节点的迭代器**。

- **循环删除安全范式（面试高频考点）**：

  C++

  ```
  std::list< int > l = {1, 2, 3, 4, 5, 6};
  
  // 需求：删除所有偶数
  for (auto it = l.begin(); it != l.end(); ) {
      if (*it % 2 == 0) {
          it = l.erase(it); // 接收返回的下一个迭代器，不可写 it++
      } else {
          ++it;
      }
  }
  ```

- **错误反例（野指针崩溃）**：

  C++

  ```
  l.erase(it);
  ++it; // 崩溃！it 所指节点已被 free，对其 ++it 触发非法内存访问
  ```

#### 2. 首尾弹出：`pop_front()` 与 `pop_back()`

- **功能**：分别移除表头第一个节点与表尾最后一个节点。
- **返回值**：`void`（不返回元素值，如需数值必须先调 `front()` 或 `back()` 读取）。
- **避坑点**：调用前必须确保 `!l.empty()`，在空链表上 `pop` 属于未定义行为。

#### 3. 值条件删除与清空

- `clear()`：清空整个链表，释放全部节点堆内存，`size()` 归零。
- `remove(const T& val)`：遍历整条链表，删除所有值等于 `val` 的节点（耗时 $O(N)$）。
- `remove_if(Predicate pred)`：根据 Lambda 或仿函数条件批量删除（耗时 $O(N)$）。

### 五、 链表独有神技：`splice()`（节点指针嫁接）

`splice` 是 `std::list` 最强大的接口，也是 LRU 缓存的核心武器。



- **底层机理**：**纯指针指针域重新赋值（Pointer Rewiring）**。断开原有节点的 `prev`/`next`，连接到目标位置。
- **代价**：**严格 $O(1)$**，零内存分配，不调用任何构造函数与析构函数，**原迭代器完全不失效**。

C++

```
// 语法形式：
dest_list.splice(pos, src_list, it);
// 将 src_list 中的 it 节点剥离，插入到 dest_list 的 pos 迭代器之前
```

#### LRU 场景用法（将命中节点移到链表头）：

C++

```
std::list< int > cache = {10, 20, 30, 40};

// 假设我们命中了 30 对应的迭代器 target_it
auto target_it = cache.begin();
std::advance(target_it, 2); // 指向 30

// 移到链表头：目标位置 cache.begin()，源链表 cache，移动节点 target_it
cache.splice(cache.begin(), cache, target_it);

// 链表现状：30 -> 10 -> 20 -> 40
// target_it 依然有效，且依然指向 30
```

### 六、 容量与状态查询

| **API 原型** | **作用**             | **复杂度** | **说明**                                                     |
| ------------ | -------------------- | ---------- | ------------------------------------------------------------ |
| `empty()`    | 判断容器是否为空     | $O(1)$     | 内部判断 `head->next == head` 或计数器为 0                   |
| `size()`     | 获取当前节点数量     | $O(1)$     | **C++11 起强制为 $O(1)$**（内部维护计数器，杜绝了老版本遍历计数的历史包袱） |
| `max_size()` | 理论支持的最大节点数 | $O(1)$     | 由系统寻址空间与 `allocator` 决定                            |

### 七、 API 避坑检查清单（Checklist）

1. **解引用越界**：绝对不能写 `*l.end()`，尾部数据应通过 `l.back()` 获取。
2. **擦除哨兵**：绝对不能写 `l.erase(l.end())`，删除尾部节点应用 `l.pop_back()` 或 `l.erase(--l.end())`。
3. **空容器访问**：在调用 `l.front()`、`l.back()`、`l.pop_front()`、`l.pop_back()` 前，必须先做 `if (!l.empty())` 检查。
4. **随机算术运算**：`std::list` 的迭代器没有重载 `+` 或 `-`，不能写 `it + 1`，只能使用 `++it`、`--it` 或 `std::advance(it, n)`。
5. **迭代器失效界限**：
   - `insert` / `emplace`：**不使任何迭代器失效**。
   - `erase` / `pop_*`：**仅使被删除节点自身的迭代器失效**，其他迭代器依然指向原本数据。
   - `splice`：**被移动的迭代器依然有效**，直接无缝跟随到新位置。
